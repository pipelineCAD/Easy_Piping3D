Easy Piping3D & BOQ

Easy Piping3D & BOQ is a desktop engineering software designed to simplify 3D piping modeling and automatically generate Bill of Quantities (BOQ) and Bill of Materials (BOM) directly inside AutoCAD.

What Easy Piping3D & BOQ Does

  • Design of any piping systems(including ventilation) in 3D inside AutoCAD
  • Convert your routing in 2D polylines into 3D piping with elevation control
  • Insert valves, branches, fittings, and any other components at any stage
  • Quickly modify or delete piping elements
  • Generate BOQ / BOM and export quantities to Excel
  • Generate BOM for multiple piping(designed by your team) and export quantities to Excel
  • Manage pipe supports with full editing and numbering tools
  • Create professional isometric drawings (ISO) with customizable settings

Pipe Support Management

Easy Piping3D & BOQ includes dedicated tools for creating and managing pipe supports directly in the 3D model.

  • Add supports by selecting locations directly on the piping centerline
  • Edit support properties at any time
  • Delete supports individually from the support table
  • Automatically display temporary support numbers for easy identification and navigation
  • Manage support information directly inside AutoCAD

Automatic Isometric Drawing Generation

Generate professional piping isometric drawings directly from your 3D model with just a few clicks.

  • Automatic ISO drawing creation from designed piping
  • Support for custom paper sizes (A3, A2, A1 and others)
  • Adjustable drawing scales
  • Optional reference point coordinates for relative dimensions
  • Drawing number prefix support
  • Developer information automatically added to title blocks
  • Consistent and standardized project documentation
